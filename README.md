# Catui Releases

Desktop installers and the auto-update feed for Catui Beta.

- macOS: download `Catui-Beta-*-arm64.dmg` (Apple Silicon) or `Catui-Beta-*-x64.dmg` (Intel).
- Windows: download `Catui-Beta-*-x64.exe` (NSIS installer).

Current builds are unsigned Beta builds for early testing. Gatekeeper/SmartScreen may warn on first launch.
